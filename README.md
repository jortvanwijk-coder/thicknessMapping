Thin-Film Thickness Analysis Code

This code was developed during an MSc at the University of Twente, as part of research into droplet technology combined with EHL point contacts.
The original thickness analysis software for the PCS ED2 rig was not precise enough, so we implemented our own MATLAB code. The result is provided here.

Features:
- 2D cross-section analysis: run_thickness2D
- 3D height map generation: run_thickness3D
- Sample images provided for testing and demonstration.

Color calibration schemes are based on the work of G. Popovici (2005) (https://ris.utwente.nl/ws/portalfiles/portal/6119644/thesis_Popovici.pdf).
